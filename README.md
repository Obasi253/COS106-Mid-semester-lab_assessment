# COS 106 Mid-Semester Lab Assessment - Academic Portfolio

## Project Overview
This repository contains a multi-page web application developed for the COS 106 course at Miva Open University. The project serves as an interactive academic portfolio that highlights my coursework, technical projects, academic planner, and contact interface.

## Repository Structure
The project is built using standard web technologies and is organized into seven core files:

- index.html: The main landing page providing an introduction and navigation hub.
- about.html: A section detailing my student background and academic background.
- projects.html: A structured grid showcase of technical builds and practical projects.
- planner.html: An interactive study and task planning tool to manage daily assignments.
- contact.html: A communication page featuring a functional form with input validation.
- style.css: The main stylesheet controlling layout, typography, colors, Flexbox navigation, and grid responsiveness.
- script.js: The JavaScript logic handling task additions on the planner and input validation on the contact form.

## Key Features
- Responsive Design: Adapts smoothly to mobile, tablet, and desktop screens using CSS Flexbox and Grid.
- Interactive Task Planner: Allows users to dynamically add and manage study tasks.
- Form Validation: Ensures user inputs are formatted correctly before submitting messages on the contact page.
- Clean Code Navigation: Simple link architecture connecting all five pages seamlessly.

## Tech Stack
- HTML5: Page content and semantic structure.
- CSS3: Custom layouts, positioning, and responsive styling.
- JavaScript: Client-side logic and DOM manipulation.
